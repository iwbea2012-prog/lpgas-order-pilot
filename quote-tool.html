見積もりアップロードツール

今ある index.html を読み込んで、完成済みの見積書（PDF/Excelなど）を見積もりタブに追加できます。基幹の見積作成フローは変わりません。
見積書ファイルは index.html に埋め込まず、別ファイルとして quotes/ フォルダにアップロードします（複数人が同時に作業しても、ファイルどうしがぶつからないようにするためです）。
この画面はネット通信をしません（最後の「書き出す」時だけ、競合確認のため公開中の index.html を読みに行きます）。

1 今の index.html を読み込む

ここに index.html をドラッグ＆ドロップ
または クリックして選択

2 見積もりを編集

見積もり一覧
新しい見積もりを追加
明細（任意・入れると「この内容で発注」ボタンが使えます）
品名型式メーカー数量単位単価

3 見積書ファイルをアップロード

今回追加した見積もりのファイル本体を、先に quotes フォルダへアップロードしてください（下のリンクから）。ファイル名は変えずにそのまま使ってください。

quotes フォルダにアップロードする（GitHub）

4 index.html を書き出す

書き出す前に、公開中の index.html を確認して、他の人が加えた変更（お知らせ・見積もり）を自動で取り込みます。合言葉は変更しない限りそのままです。

  2. GitHub のリポジトリ画面 → Add file → Upload files（または .../upload/main）で、今ダウンロードした index.html を上書きアップロード → Commit。
  3. 2〜3分後、アプリの見積もりタブに反映されます。
