発注アプリ ビルダー

この販売店の購入履歴CSVを、暗号化した index.html（スマホ用の発注アプリ）に変換します。
この画面はネット通信をしません。CSVの中身はこのブラウザの中だけで処理され、外部に送信されません。
CSVはこのページ以外（メール・チャット等）に貼らないでください。

1 購入履歴CSVを読み込む

ここにCSVファイルをドラッグ＆ドロップ
または クリックして選択

2 列の対応づけ

* は必須。定価は対象外です（アプリ側で手入力）。

3 この販売店の設定

4 合言葉を決めて生成

スマホでアプリを開くときに入力する合言葉です。この販売店とだけ共有します。

—
選んだ場合、上の合言葉（変更していなければ今までと同じもの）で復号できれば、既存のお知らせ・見積もり・納期回答をそのまま新しい index.html に引き継ぎます。
✅ index.html を書き出しました。
  1. GitHub のリポジトリ画面 → Add file → Upload files（または .../upload/main）で、今ダウンロードした index.html を上書きアップロード → Commit。
  2. 2〜3分後、販売店のスマホのホーム画面アイコンから開くと最新になります（合言葉は初回だけ）。
  3. CSV とこの builder.html はアップロードしないでください。
